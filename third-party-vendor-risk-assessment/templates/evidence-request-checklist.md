# Vendor Evidence Request Checklist

## Governance and Assurance

- [ ] SOC 2 Type II report and bridge letter
- [ ] ISO 27001 certificate and scope
- [ ] Information security policies
- [ ] Security organization chart and accountability matrix

## Technical Security

- [ ] Architecture and data-flow diagrams
- [ ] IAM, MFA, SSO, and access-review evidence
- [ ] Encryption and key-management standards
- [ ] Vulnerability-management policy and metrics
- [ ] Penetration-test report and retest evidence
- [ ] Secure-development and change-management standards
- [ ] SIEM, logging, and incident-monitoring evidence

## Privacy and Data Protection

- [ ] Data inventory and classification
- [ ] Processing-purpose and residency statement
- [ ] Data retention and secure-deletion standard
- [ ] Data Processing Agreement
- [ ] Subprocessor register and processing locations
- [ ] Privacy-impact assessment and data-subject request procedure

## Resilience and Incident Response

- [ ] Incident response plan
- [ ] Most recent tabletop exercise report
- [ ] BCP/DR plan
- [ ] Recovery-test results
- [ ] Backup and restoration-test evidence

## Legal and Financial

- [ ] Master Services Agreement
- [ ] Security addendum
- [ ] Service Level Agreement
- [ ] Cyber-liability insurance certificate
- [ ] Financial-health evidence
