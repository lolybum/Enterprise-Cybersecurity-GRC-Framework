# Enterprise-Cybersecurity-GRC-Framework
Enterprise-grade Cybersecurity Governance, Risk, and Compliance (GRC) framework featuring information security policies, governance documentation, risk management processes, compliance mappings, and security program artifacts aligned with NIST CSF 2.0, NIST SP 800-53 Rev. 5, ISO/IEC 27001:2022, CIS Controls v8, and COBIT 2019.
