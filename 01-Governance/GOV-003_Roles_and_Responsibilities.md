# 1. Purpose

This document defines the information security roles and responsibilities for Apex Technologies. It establishes accountability for protecting customer data, company systems, cloud infrastructure, source code, employee information, and business operations.

Clear roles and responsibilities support effective governance, risk management, regulatory compliance, incident response, and operational resilience.

---

# 2. Scope

This document applies to:

- Executive Leadership
- Chief Information Security Officer
- Information Security Team
- IT Operations
- Engineering Team
- Human Resources
- Legal and Compliance
- Finance
- Department Managers
- Employees
- Contractors
- Third-party vendors
- Cloud service providers

---

# 3. Executive Leadership Responsibilities

Executive Leadership is responsible for providing strategic oversight of the Information Security Program.

Responsibilities include:

- Approving information security strategy
- Approving cybersecurity budget
- Reviewing enterprise cyber risks
- Supporting security policies and standards
- Promoting a security-aware culture
- Ensuring security aligns with business objectives
- Reviewing major security incidents
- Supporting regulatory and contractual compliance

---

# 4. Chief Information Security Officer Responsibilities

The Chief Information Security Officer is responsible for leading the Information Security Program.

Responsibilities include:

- Developing security governance documentation
- Maintaining security policies, standards, and procedures
- Managing enterprise cyber risk
- Reporting risks to executive leadership
- Coordinating security awareness training
- Overseeing incident response
- Supporting vendor risk management
- Maintaining security metrics
- Coordinating compliance activities
- Reviewing policy exceptions

---

# 5. Information Security Team Responsibilities

The Information Security Team is responsible for implementing and monitoring security controls.

Responsibilities include:

- Monitoring security events
- Supporting vulnerability management
- Reviewing access controls
- Supporting incident response
- Conducting security reviews
- Maintaining security documentation
- Supporting audit requests
- Tracking remediation activities
- Reporting control gaps

---

# 6. IT Operations Responsibilities

IT Operations is responsible for secure administration of technology systems.

Responsibilities include:

- Managing company laptops
- Applying security patches
- Enforcing endpoint protection
- Managing device configuration
- Supporting account provisioning
- Supporting account deprovisioning
- Maintaining asset inventory
- Supporting backup and recovery
- Enforcing approved technical standards

---

# 7. Engineering Responsibilities

Engineering is responsible for secure software development and protection of source code.

Responsibilities include:

- Following secure coding practices
- Protecting GitHub repositories
- Reviewing code before deployment
- Supporting vulnerability remediation
- Protecting application secrets
- Using approved development tools
- Supporting application security testing
- Reporting security weaknesses
- Implementing security requirements in software design

---

# 8. Human Resources Responsibilities

Human Resources supports security governance through employee lifecycle management.

Responsibilities include:

- Supporting background screening where applicable
- Coordinating security awareness requirements
- Notifying IT of onboarding events
- Notifying IT of employee termination events
- Supporting disciplinary actions related to security violations
- Maintaining employee policy acknowledgments
- Supporting insider risk processes

---

# 9. Legal and Compliance Responsibilities

Legal and Compliance supports regulatory, contractual, and legal obligations.

Responsibilities include:

- Reviewing customer security requirements
- Supporting privacy obligations
- Reviewing vendor contracts
- Supporting incident notification decisions
- Reviewing policy exceptions when required
- Supporting audit and compliance activities
- Advising on legal and regulatory risk

---

# 10. Finance Responsibilities

Finance is responsible for supporting financial controls related to cybersecurity.

Responsibilities include:

- Supporting cybersecurity budget planning
- Reviewing cyber insurance requirements
- Supporting vendor payment controls
- Protecting financial records
- Supporting fraud prevention controls
- Participating in business continuity planning

---

# 11. Department Manager Responsibilities

Department Managers are responsible for enforcing security requirements within their teams.

Responsibilities include:

- Ensuring employees follow security policies
- Reviewing access requests
- Reporting security concerns
- Supporting security awareness completion
- Participating in risk assessments
- Approving business access needs
- Escalating policy violations

---

# 12. Employee Responsibilities

All employees are responsible for protecting Apex Technologies information assets.

Responsibilities include:

- Following security policies
- Protecting passwords and MFA devices
- Reporting suspicious activity
- Using approved systems and tools
- Protecting company laptops
- Avoiding unauthorized software
- Handling data according to classification requirements
- Completing security awareness training
- Reporting lost or stolen devices immediately

---

# 13. Contractor Responsibilities

Contractors must follow the same security expectations as employees.

Responsibilities include:

- Using only approved systems
- Protecting Apex Technologies data
- Following access control requirements
- Reporting security incidents
- Returning company assets when engagement ends
- Complying with confidentiality requirements

---

# 14. Third-Party Vendor Responsibilities

Third-party vendors must protect Apex Technologies data and systems according to contractual requirements.

Responsibilities include:

- Maintaining appropriate security controls
- Reporting security incidents affecting Apex Technologies data
- Protecting customer and company information
- Supporting vendor risk assessments
- Complying with contractual security obligations
- Notifying Apex Technologies of material control failures

---

# 15. Cloud Service Provider Responsibilities

Cloud Service Providers support the infrastructure and platform services used by Apex Technologies.

Apex Technologies remains responsible for securing its cloud configurations, identities, data, applications, and access controls under the shared responsibility model.

Cloud governance responsibilities include:

- Reviewing AWS configurations
- Managing IAM permissions
- Monitoring cloud activity
- Protecting storage services
- Reviewing cloud logging
- Managing cloud security risks

# 17. Segregation of Duties

Apex Technologies shall maintain segregation of duties to reduce fraud, error, and unauthorized activity.

Examples include:

- Access request approval shall be separate from access provisioning.
- Code development shall be separate from production approval where feasible.
- Security monitoring shall be independent from system administration where feasible.
- Vendor approval shall be separate from vendor payment processing.
- Policy exception approval shall require appropriate management review.

---

# 18. Reporting Requirements

Security responsibilities shall be monitored through:

- Access review reports
- Security awareness reports
- Vulnerability reports
- Incident reports
- Audit findings
- Vendor risk reports
- Policy exception reports
- Risk register updates

Reports shall be reviewed by the CISO and escalated to Executive Leadership where necessary.

---

# 19. Exceptions

Exceptions to this document require:

- Business justification
- Risk assessment
- Compensating controls
- CISO review
- Executive approval where required
- Defined expiration date

Approved exceptions shall be documented and reviewed periodically.

---

# 20. Enforcement

Failure to comply with assigned security responsibilities may result in:

- Security retraining
- Access removal
- Disciplinary action
- Contract termination
- Legal action where applicable
