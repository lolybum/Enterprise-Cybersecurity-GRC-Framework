# Enterprise Security Policies

## Overview

This directory contains the organization's enterprise information security policies that establish mandatory requirements for protecting information assets, managing cyber risk, and maintaining compliance with regulatory and industry standards.

The policies in this repository are modeled after documentation commonly maintained by enterprise Information Security and Governance, Risk, and Compliance (GRC) teams.

# Policy Objectives

The objectives of these policies are to:

- Protect organizational information assets
- Establish enterprise security governance
- Reduce cybersecurity risk
- Support regulatory compliance
- Define security responsibilities
- Standardize security processes
- Promote security awareness
- Enable continuous improvement
