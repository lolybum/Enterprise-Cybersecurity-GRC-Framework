# Enterprise Security Policy Library

## Overview

The Enterprise Security Policy Library contains the organization's approved cybersecurity governance policies that establish mandatory security requirements, governance expectations, and compliance obligations across the enterprise.

These policies support the Enterprise Information Security Program and align with internationally recognized frameworks including:

- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-53 Rev. 5
- ISO/IEC 27001:2022
- ISO/IEC 27002:2022
- CIS Controls v8
- COBIT 2019
- NIST AI Risk Management Framework
- NIST Privacy Framework

# Policy Ownership

All enterprise security policies are owned by the **Chief Information Security Officer (CISO)** and are reviewed at least annually or following significant business, regulatory, or technology changes.

---

# Policy Lifecycle

Every policy follows the same governance lifecycle:

1. Draft
2. Internal Review
3. Security Review
4. Legal & Compliance Review
5. Executive Approval
6. Publication
7. Annual Review
8. Revision
9. Retirement (when applicable)
