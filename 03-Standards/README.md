# Enterprise Security Standards

## Overview

The Enterprise Security Standards define the mandatory technical, operational, and administrative requirements used to implement the organization's cybersecurity governance policies.

Security standards establish minimum security baselines that must be followed across enterprise systems, applications, cloud environments, endpoints, networks, and business operations.

These standards support the Enterprise Cybersecurity Governance Framework and align with internationally recognized cybersecurity frameworks.

---

# Framework Alignment

Enterprise Security Standards align with:

- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-53 Rev. 5
- ISO/IEC 27001:2022
- ISO/IEC 27002:2022
- CIS Controls v8
- COBIT 2019
- NIST Zero Trust Architecture (SP 800-207)

# Relationship to Enterprise Policies

Enterprise Security Standards support and implement the organization's Enterprise Security Policies by defining specific technical and operational requirements necessary to achieve policy objectives.

Policies establish governance expectations, while standards define the minimum controls and security baselines required for implementation.
