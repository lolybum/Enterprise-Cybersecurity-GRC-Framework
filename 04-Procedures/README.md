# Enterprise Cybersecurity Procedures

## Overview

Enterprise procedures provide step-by-step operational instructions for implementing the organization's cybersecurity policies and standards.

Policies define **what** must be accomplished.

Standards define **minimum technical and administrative requirements**.

Procedures define **how authorized personnel perform security activities consistently and securely**.

All procedures are reviewed annually and updated following significant regulatory, technology, business, or threat landscape changes.
